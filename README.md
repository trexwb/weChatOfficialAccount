# 公众号HTML插入助手

Chrome 浏览器扩展（Manifest V3），在微信公众号文章编辑页提供悬浮按钮，用于插入自定义 HTML 内容。

## 功能特性

- 悬浮按钮入口，等待编辑器就绪后激活（悬浮提示会显示状态）
- **CodeMirror 代码编辑器**：HTML 语法高亮、行号、括号匹配、多行缩进（Tab / Shift+Tab）
- **查找替换**：`Cmd/Ctrl+F` 打开搜索面板（CodeMirror 原生）
- 分屏 / 代码 / 预览三种视图，预览自动同步（防抖）
- **模板库**：保存常用代码段为模板、一键插入、删除管理（chrome.storage，与设置页共享）
- **设置页**（右键扩展图标 → 选项）：模板重命名/删除/导出/导入/清空，净化默认开关
- **右键菜单**：页面选中文字 → 右键 →「插入选中内容到公众号编辑器」直接带入弹窗
- **草稿自动保存**：关闭弹窗后下次打开自动恢复内容
- **格式化 / 压缩**：一键美化或压缩 HTML
- **公众号适配净化**：插入时移除 script/事件属性，检查未闭合标签并提示
- **表格生成**：粘贴 Excel 复制区域或 CSV，自动生成公众号表格 HTML
- **双向同步**：弹窗打开期间，公众号编辑器内的改动自动反映到弹窗
- 一键读取公众号编辑器当前内容
- 非破坏性插入：编辑器内有选区时替换选区（全选即整体替换），无选区时追加到文章末尾
- 弹窗可拖动、可缩放（右下角拖拽调整大小）
- 深色模式：跟随系统 `prefers-color-scheme`
- 平台自适应快捷键提示（⌘↵ / Ctrl+Enter），Esc 关闭
- 平台注册表架构（PLATFORMS），公众号编辑器选择器三级回退

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录

## 使用

1. 打开公众号文章编辑页（`mp.weixin.qq.com` 的编辑页面）
2. 点击右下角悬浮按钮打开弹窗
3. 输入或粘贴 HTML；可点击「读取」将编辑器现有内容载入后修改
4. 在预览视图中确认效果，点击「插入到编辑器」

**快捷入口**：在编辑页选中文字后右键 →「插入选中内容到公众号编辑器」，弹窗打开并自动载入选中内容。

**设置页**：`chrome://extensions` → 本扩展「详情」→「扩展程序选项」，或右键扩展图标 → 选项。

| 快捷键 | 功能 |
| --- | --- |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进（多行选区整体生效） |
| `Cmd/Ctrl+F` | 查找替换 |
| `Cmd/Ctrl+Enter` | 插入到编辑器 |
| `Esc` | 关闭弹窗（搜索框/表格子窗口打开时先关闭它们） |

## 目录结构

```
WeChatOfficialAccount/
├── manifest.json       # MV3 清单（版本真源）
├── content.js          # 页面注入核心逻辑（平台注册表/弹窗/CodeMirror/插入/净化/同步）
├── background.js       # Service Worker：右键菜单
├── options.html/js     # 设置页：模板管理 + 净化默认值
├── styles.css          # 全部样式（含深色模式）
├── lib/codemirror/     # CodeMirror 5 本地依赖（按 manifest 顺序加载）
├── AGENTS.md           # AI Agent 开发规范（所有 AI 开发前必读）
└── README.md
```

## 开发说明

- **AI 开发前必读 `AGENTS.md`**：版本规则（MINOR/MAJOR 需用户决定，禁止 git 提交）、平台扩展规范、存储规范、测试清单
- 编辑器选择器定义在 `content.js` 顶部 `PLATFORMS` 注册表（当前仅公众号，三级回退）
- Chrome match patterns 无法按 query 过滤 URL，编辑页判定在 `content.js` 运行时完成（`action=edit`）
- CodeMirror 5 以 UMD 单文件引入（`lib/codemirror/`），加载顺序见 `manifest.json`，升级依赖时保持顺序
- 模板/设置存 `chrome.storage.local`（content script 与设置页共享）；草稿存页面 localStorage（key: `wx-ext-state-v1`）
- 备份文件 `*.bak-<版本>` 用于回滚；变更未提交 git，提交由维护者自行决定
