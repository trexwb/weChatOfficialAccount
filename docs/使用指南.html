一、安装与加载

打开扩展管理页Chrome 地址栏输入 chrome://extensions 回车
开启开发者模式右上角「开发者模式」开关打开
加载扩展目录点击「加载已解压的扩展程序」，选择本项目目录（含 manifest.json 的根目录）
💡 修改代码后：在 chrome://extensions 点「重新加载」，并刷新公众号编辑页（两步都要，否则旧页面会提示扩展上下文失效）。

二、快速上手

打开公众号文章编辑页地址形如 mp.weixin.qq.com/cgi-bin/appmsg?...&action=edit...，等待右下角悬浮按钮就绪（提示从「等待编辑器…」变为「插入 HTML」）
点击悬浮按钮打开弹窗默认分屏视图：左侧代码、右侧实时预览
输入或粘贴 HTML可点标题栏「读取」按钮载入编辑器现有内容；或点「模板 ▾」插入常用代码段
预览确认后插入点「插入到编辑器」或按 ⌘↵ / Ctrl+Enter。编辑器内有选区时替换选区（全选 = 整体替换），无选区时追加到文章末尾
⚠️ 插入是「追加/替换选区」，不会清空文章已有内容——这是设计行为，可放心使用。

三、功能详解

代码编辑器 核心

CodeMirror 引擎：HTML 语法高亮、行号、括号匹配、智能缩进。Tab 缩进、Shift+Tab 反缩进，多行选区整体生效。

查找替换 核心

弹窗内按 ⌘F / Ctrl+F 打开搜索面板，支持替换；长 HTML 定位利器。

模板库 高频

「模板 ▾」保存当前内容为模板、一键插入、删除管理；数据存 chrome.storage，与设置页双向同步。

草稿自动保存 高频

输入内容防抖自动保存，关闭弹窗后重新打开自动恢复；插入成功后自动清除草稿。

格式化 / 压缩

一键按标签嵌套美化代码；一键压缩体积（保留 pre/script 等原样内容）。

公众号适配净化 默认开启

插入时移除 script/iframe/事件属性，检查未闭合标签并提示；可点按钮关闭。

表格生成

粘贴 Excel 复制区域（Tab 分隔）或 CSV，自动识别分隔符与引号，生成带表头的公众号表格 HTML。

跨页面右键插入

任意网页选中文字 → 右键 →「插入选中内容到公众号编辑器」，自动找到已打开的编辑页并切入弹窗。

双向同步

弹窗打开期间，公众号编辑器内的改动（防抖 800ms）自动反映到弹窗代码区。

弹窗拖动 / 缩放

标题栏拖动移动弹窗；右下角拖拽调整大小（最小 640×420）。

深色模式

跟随系统 prefers-color-scheme 自动切换，含代码高亮配色。

减弱动态效果

系统开启「减弱动态效果」时自动关闭动画，关闭弹窗有定时兜底，不会残留。

净化按钮详解

「净化」是插入前的一道自动清理工序（绿色高亮 = 开启）。它会：

处理内容原因
移除标签script / iframe / object / embed / link / meta / base / form公众号保存时会过滤，提前移除避免插入后丢失或保存异常
移除事件属性所有 on* 属性（onclick、onerror 等）公众号不支持且属安全隐患
闭合检查统计开闭标签数量差并警告未闭合标签会让编辑器渲染错乱

净化只影响插入输出，不改动编辑区代码；发现问题会黄色 toast 提示前 3 条。

四、快捷键速查

快捷键功能适用位置
Tab / Shift+Tab缩进 / 反缩进（多行选区整体生效）代码编辑区
⌘F / Ctrl+F查找替换代码编辑区
⌘↵ / Ctrl+Enter插入到编辑器代码编辑区
Esc关闭弹窗（搜索框/表格子窗口打开时先关闭它们）全局
右键菜单选中文字 →「插入选中内容到公众号编辑器」（跨页面）任意网页

五、工作流程

入口悬浮按钮 / 右键菜单 / 跨页面插入
→
编辑弹窗CodeMirror 编辑 + 预览 + 模板 + 草稿
→
净化（可选）去脚本/事件属性 + 闭合检查
→
插入替换选区 / 追加末尾

插入走 DOM 层 + 事件通知，公众号编辑器改版时靠「三级选择器回退」保持兼容。

六、常见问题排查

悬浮按钮没出现，或点击无反应？

1) 确认当前是文章编辑页（URL 含 action=edit）；2) 扩展重载后必须刷新页面（扩展上下文失效会静默无反应）；3) 按钮提示「等待编辑器…」说明编辑器未就绪，稍等即可。

点「模板」报 Extension context invalidated？

扩展在 chrome://extensions 被重新加载后，旧页面仍运行失效的脚本。刷新页面即可；新版本已内置兜底，会提示「请刷新页面后重试」而非报错。

右键「插入选中内容」没反应？

1) 需要先打开一篇文章的编辑页标签（跨页面插入依赖它）；2) 工具栏徽标 ✗ = 未找到编辑页，! = 页面处理出错，✓ = 成功；3) 扩展重载后旧页面会自动注入恢复，仍失败就刷新一次编辑页。

插入后样式/结构丢失？

公众号保存文章时会过滤部分标签与属性。开启「净化」可提前移除并提示；若确实需要某些标签（如 iframe），请确认公众号是否支持该场景。

提示「未找到公众号编辑器」？

公众号编辑器为懒加载，等待悬浮按钮变为就绪状态后再操作；若持续报错，可能是页面结构改版，请反馈控制台信息以便更新选择器。

深色模式没生效？

扩展跟随系统 prefers-color-scheme，需系统处于深色外观；浏览器内也可强制指定。

七、设置页说明

入口：chrome://extensions → 本扩展「详情」→「扩展程序选项」（或右键扩展图标 → 选项）。

设置项说明
模板管理重命名 / 删除 / 导出 JSON / 导入 JSON（同名覆盖、其余追加）/ 清空全部
净化默认开关控制弹窗内「净化」按钮的默认状态（默认开启）

模板与设置存于 chrome.storage.local，弹窗与设置页实时共享。
